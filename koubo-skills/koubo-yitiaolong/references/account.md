## 配色

| 用途 | 颜色 |
|---|---|
| 全片主色 | 黑、白、黄 |
| 图解：墨黑 / 荧光黄 / 橙 / 灰 | `#222226` / `#FFD640` / `#E27A1C` / `#78767A` |
| 封面标题黄（奶油黄） | `#F5F2C4` |
| 字幕金句黄（柠檬黄） | `#FFE45A` |

“标题那种黄”= 封面奶油黄，不是字幕金句黄。颜色有歧义时先问是哪个元素，或从博主给的图里取样。

## 已知的坑

- 混音会吞结尾：混音后检查总时长和最后 3 秒，以人声轨长度为准。
- 补录片段响度要和正片对齐（某期补录比正片小 8.5 dB）。
- 封面照：眼镜避开屏幕和窗户，背景清空，正面光。过曝和镜片反光的照片通常要退回重拍。
- 每期结束把新踩的坑补进对应 skill，并在项目 `复盘/` 里记一篇。
