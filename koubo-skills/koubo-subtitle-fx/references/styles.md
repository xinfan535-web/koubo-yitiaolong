# 样式规格（竖屏 1080×1920 的数值；横屏差异见文末）

这套规则来自两条剪辑示范（同一位知识口播博主的小红书竖屏视频），逐帧拆出来的。

| 样式 | 字体 | 颜色 | 位置 | 动画 |
|---|---|---|---|---|
| 普通字幕 | 黑体最粗（Noto Sans CJK/SC Black；剪映用思源黑体 Heavy）70px | 白字 + 深灰半透明圆角底 | 画面 68% 高度居中（y≈1300），不放最底部（避开平台标题/按钮） | 无，直接切 |
| 金句 gold | 站酷快乐体 84px（big 116px） | 柠檬黄 #FFE45A，深色细描边 + 软阴影 | 普通字幕位置，多行往下叠 | 放大弹出 20%→110%→100%，0.22 秒 |
| 爆点 punch | 站酷快乐体 168px | 柠檬黄 + 粗描边，末尾蓝色 #3BA7FF 爆炸星 | 字幕位置略上 | 0→115%→100% 弹出，星星晚 0.06 秒 |
| 关键词 keywords | 站酷快乐体 78px | 柠檬黄 | 字幕高度，左起横排 | 逐词出现，每词逐字淡入 |
| 章节 chapter | 黑体最粗，序号 120px，标题 62px 加字距 | 深红 #B3262E 条 + 白字 | 先居中（字幕高度），再缩 50% 挂左上角 | 红条从左擦入 → 序号淡入 → 标题逐字 |
| 清单 checklist | 站酷快乐体 68px | 黄色圆角方块 + 白勾，白字深阴影 | 左上角，一条一行 | 方块弹出 → 勾 → 文字逐字 |
| 批注/设问 note | 站酷快乐体 64px | 白（批注）/ 黄（设问） | 人物旁边或字幕上方，倾斜 5° | 逐字淡入 |
| 贴纸 sticker | 站酷快乐体 76px | 黄色 #FFD84D 胶囊 + 棕字 #5A3A1A | 贴在物件旁 | 弹出，微倾 −4° |
| 标签 booktag | 站酷快乐体 66px | 黄底圆角 + 白字黑描边 | 字幕上方偏左 | 弹出 |
| 画面缩框 shrink | — | 画面缩到 86%，圆角，四周黑 | 居中 | 硬切进出，持续这句金句的时长 |

普通字幕文字规则：去掉所有标点（换成空格），一屏一句，**竖屏不超过 14 字、横屏不超过 20 字**；超了优先在原标点处断开，按字数分时长；口头禅“嗯/啊/那个”删掉，其余保留原话。

## plan.json 字段

- 顶层：`srt`（字幕文件）、`config`、`events`。
- `config`：`orient`（`"landscape"` 为横屏，默认竖屏）、`base_y`（普通字幕中心 y）、`base_size`、`max_chars`、`shrink`（缩框比例，默认 0.86）。
- 每个 event 必有 `type`、`start`、`end`；其余按类型：
  - `gold`：`text` 或 `lines`+`line_starts`；`big`（布尔）；可选 `y`。
  - `punch`：`text`、可选 `size`、`y`。
  - `keywords`：`words: [[词, 开始秒], …]`、可选 `x`、`y`、`size`。
  - `chapter`：`num`、`title`、`hold`（居中停留秒，默认 1.6）、`pin_y`。
  - `checklist`：`items: [[文字, 开始秒], …]`、`x`、`y`。
  - `note`：`text`、`x`、`y`、`color`（`"yellow"` 为设问）、`angle`、`replace`。
  - `sticker`：`text`、`x`、`y`、`angle`；`booktag`：`text`、`x`、`y`。
  - `shrink`：只要 `start`、`end`。
- 会让普通字幕让位的：`gold`、`keywords`、`punch`、`chapter`，以及加了 `"replace": true` 的任何 event。

## 剪映里手动做的对应方法

- 金句/贴纸/标签：文字入场动画选“放大”或“弹入”，时长 0.2–0.3 秒。
- 关键词/清单/批注/章节标题：入场动画选逐字类（打字机、逐字显影）。
- 章节红条：文字加背景色块或矩形贴纸，入场选“向右擦除”；缩到左上角那段单独复制一份缩小放左上角。
- 画面缩框：在金句那段视频上打两个关键帧，缩放 100%→86%（硬切就两帧挨着），画布背景设黑色，加矩形蒙版调圆角。

## 画面层要素（字幕之外，参考视频也在用）

做口播剪辑时一起提醒博主；脚本不自动做，需要素材，在标注表“说明”列写“此处切 B-roll：xxx”：

- **说到什么就切什么**：讲到桌下踏板切桌下特写；B-roll 2–4 秒一切，人声不断。
- **讲书/内容原文**：切书页特写，右上角圆形小窗放博主的脸，正在读的那一行画红色下划线并跟着读到哪移到哪。
- **讲故事情节**：插插画或截图，横图放竖屏时用同一张图模糊放大铺底。
- **景别变化**：同一机位在中景和近景之间切（裁切放大 110–120%），每句或每两句换一次。

## 横屏（1920×1080）

- 字幕条：黑色圆角条，中心 y≈1010，字号 74，≤20 字（脚本在 `orient: landscape` 时自动用这些默认值）。
- 金句缩字的宽度上限是 W−100。章节、清单、批注、贴纸、标签的默认位置仍是竖屏值，横屏必须显式写 x/y。
