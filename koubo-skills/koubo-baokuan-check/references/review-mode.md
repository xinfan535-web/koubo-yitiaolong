# 复盘模式：用数据定位卡点

只在拿到已发布视频的后台数据时读这个文件。

基线用**账号自己最近 10 条的中位数**，不用行业数字。对照下表判断实际卡在哪一关：

| 现象 | 最可能卡在 | 回看稿子的哪里 |
|---|---|---|
| 播放停在小流量池，各项比率正常 | 第一关：选题上限 | 人群层级、处境挂钩 |
| 2 秒跳出高 / 5 秒完播低 | 第二关：开头缺口 | 第一句、标题封面对齐 |
| 开头留住了，平均播放时长短、完播低 | 第三关：中段留存 | 流失曲线下坠点对应的那一段 |
| 完播不错，播放不涨 | 第四关：传播放大 | 金句、转发对象 |
| 收藏高、转发低 | 做成了清单，缺判断 | 核心判断句 |

做法：

1. 没给基线数据时，先说明结论是相对判断，再请对方补最近几条的数据。
2. 有流失曲线截图时，把下坠点对应到具体那一句话，引原文。
3. 输出仍用主文件的固定格式，在“最先卡住的地方”里写数据依据（哪个指标、比基线高/低多少）。
4. 结论写进当期项目的 `复盘/` 文件夹；新踩的坑补进对应 skill。
