# 口播封面和标题

口播一条龙的第 4 步。你出标题候选和封面，博主定。
成品参照：上一期 `成片/` 里的封面（短版、长版）；横屏样张放在你自己的 `_工具/横屏示例/`。做新封面前先打开对齐，**颜色直接从图里取样，不凭印象**。版式数值在 [references/layouts.md](references/layouts.md)。

## 标题

- 全标题 ≤ 20 字，分两行，每行 5–8 字。必须有反差：和常识反着说，或大词配小结论。例：“大多数人根本 / 不需要造Agent”“AI圈最火3个词 / 一次全讲明白”。
- 第一行铺垫，第二行是重点（竖屏版第二行标黄）。标题的承诺要和视频第一句、正片内容对得上。
- 长版和短版用不同标题，各出 3 个候选。副标题一句，说清具体讲什么，口语，如“agent/harness/skill到底啥区别？”。

## 版式（按画幅选）

- **竖屏 1080×1440（3:4）**：两行大标题（压窄特粗宋体，第一行暖白，第二行奶油黄 `#F5F2C4`，带柔和投影）→ 黑色胶囊副标题 → 人物抠图加白描边贴纸（占下方约 3/5，底部出画）。背景三选一：虚化界面截图、方格纸、纯暖白，都要浅淡不抢字。全图只有黑、白、黄。
- **横屏视频**：明亮极简——上半是横屏画面加白色手写字，下半浅色底加一张白卡片；人物头要小，背景要虚化。发小红书时用 3:4 竖图（已有样张）；B 站 16:9 版同一风格，**还没出过样张**，先和用户确认再做。
- 竖屏还有几个测试版（拼图背景、深色去背景等），用户**还没选定**用哪个；她没指定就按上面的主版式出，并说明其他版式可选。

## 人物照片

挑表情有精神、眼睛看镜头、有手势（指向标题、拿笔）的；可以从正片抽帧，也可以用她单独拍的。

- **不动脸**：不磨皮、不调五官、不提亮到过曝（过曝版被退回过），只加轻度锐化。
- 抠图用 `python3 scripts/cutout.py 照片.png 抠图.png`（需要 `pip3 install 'rembg[cpu]'`）。抠完放大看头发丝和镜框边缘，宁可略收一点，不要带背景残留。白描边均匀，约 10–14 像素，外面可加很轻的投影。
- 照片不合格就直接请她重拍，并给要求：眼镜避开屏幕和窗户，镜片不要有大块反光；背景清空，不站书架前（白墙最好）；正面光，脸上没有明显阴影；竖拍，留出头顶和肩膀。

## 步骤

1. 出标题候选和副标题，等博主选。
2. 选照片并说明为什么选这张；不合格就请她补拍。
3. 抠图 → 描边 → 排版 → 出图（脚本见下）。
4. 缩到信息流小图尺寸（宽约 360）看一眼：标题还能不能一眼读完。
5. 长版、短版各一张，发给她确认。

## 脚本现状

排版脚本是当期的测试脚本，存在你自己的 `~/projects/口播/_工具/封面/`（`cover_e.py` 拼图版、`cover_xhs_land.py` 横屏明亮极简版），**写死了云端路径和当期素材，没做通用化，不能直接用**；它们的用法和依赖见该目录的 `说明.md`。本 skill 只带通用的 `scripts/cutout.py`。做封面时用 Pillow 按 references/layouts.md 的数值现写排版，写顺了再存进本 skill 的 `scripts/` 并在这里补用法。
字体用 `scripts/fontkit.py`（`import fontkit; fontkit.truetype("serif_black", 120)` 取思源宋体 Black，`"kuaile"` 取站酷快乐体，`"hand"` 取霞鹜文楷），缺字体运行 `bash ../koubo-yitiaolong/scripts/get_fonts.sh`。
