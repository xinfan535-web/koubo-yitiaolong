# 口播逐字稿

口播一条龙的第 1 步。输入选题（加资料、对标视频、博主自己的想法），输出博主照着就能录的逐字稿。
账号定位：运营人看 AI，观众是想用 AI 的运营和职场人，不默认懂技术。身份钩子的措辞见同一 skills 目录下的 koubo-yitiaolong/references/account.md。

## 开写之前

1. **选题过自检**：有 koubo-baokuan-check 就先跑选题模式；结论是“换角度”就先改选题，不写稿。
2. **写出核心判断**：用一句可以被反驳的话写出这条视频的结论。写不出，说明还只是资料整理，回去找判断。
3. **确认资料来源**：事实、数据、产品信息都要有出处。没有出处的不写，或明确标成博主的个人看法。
4. **有对标视频先拆**：只拆讲法（怎么开头、怎么切画面、节奏），不抄内容。

信息不够时只问最关键的一个问题，通常是“这条你自己的判断是什么”。

## 写稿规则

**1. 开头：10 秒内给答案**
- 第一句就进正题，不自我介绍、不铺垫、不说“今天聊聊”。
- 前 10 秒（约 40–50 字）结束时，观众已拿到结论，或明确知道看完能得到什么。
- 钩子只选一个主类型，最多叠一个辅助（有 ra-hook skill 就用它的决策流程；没有就从“价值包装 / 直击痛点 / 话题开场 / 现象前置”里选）。AI 实操教程类优先价值包装或直击痛点，观点类优先话题开场或现象前置。
- 钩子给的承诺正片必须兑现。出 3 个不同类型的开头让博主挑，标明类型。

**2. 中段：按完播排节奏**
- 目标完播率 40%。每约 10 秒（40–50 字）必须有一次“兑现”或“开新缺口”，连续两段都没有就删或重写。
- 视频一半左右安排一次重启预期：反转、更大的问题、最容易被误解的一点。
- 判断在前，解释在后。一条视频只讲一个判断，支撑点 2–3 个，多了拆成两条。
- 每个抽象概念配一个博主自己的真实例子或一个画面（图解/网页）。

**3. 口语化**
- 一句一个意思，一口气能读完；用博主平时说话的词；术语第一次出现用一句大白话带过。
- 写完过一遍去 AI 腔清单（没有 ra-renhua skill 就自己按这条做）：去掉“不是 A 而是 B”“其实 / 本质上 / 真正”“更重要的是”和冒号讲义腔。
- 不新增博主没说过的经历、数据、引用。

**4. 标注画面**（后面的环节照着做素材）
- **【图解N：一句话说明画什么】**：概念、流程、对比 → whiteboard-diagram。
- **【素材N：页面名 + 网址 + 要指给观众看的位置】**：真实网页、产品、文档 → web-page-demo。
- 讲法是“指着屏幕讲”，不设计复杂点击操作；提到任何产品或出处都配真实页面，不用示意图代替。
- 5 分钟长版图解和素材合计 8–12 段，纯人脸不连续超过 40 秒。图解和素材各自从 1 连续编号。

**5. 结尾**
- 不说“最后”“总结一下”。最后一个信息点讲完直接接身份钩子，每期措辞可微调，身份和视角不变。
- 想要评论就给一个可以站队或能说“我也是”的具体问题，不问“你怎么看”。

**6. 长度**：长版约 5 分钟、1300–1500 字；短版约 1.5 分钟、350–450 字。

## 短版怎么出

短版不重写，用“补录钩子 + 正片片段”拼：

1. 从长版里挑最强的一个判断和它的支撑段。
2. 单独写一个更狠的开头钩子，需要博主补录。
3. 列出要用的正片句子（标长版段落号），保证不看长版也听得懂。
4. 结尾同样接身份钩子。

稿子里把需要补录的句子单独列出来，方便一次录完；补录音量后期要和正片对齐，交接时提醒剪辑环节。

## 输出格式

```
# <选题>｜口播逐字稿
核心判断：<一句话>　钩子类型：<主类型（+辅助）>　预计时长：长版约 X 分 X 秒 / 短版约 X 分 X 秒

## 开头备选
A（类型）：…　B（类型）：…　C（类型）：…

## 长版正文
[开场] …
[章节名 2–4 字] …【图解1：…】…【素材1：… / 网址 / 指哪里】
[结论] …
[身份钩子] …

## 短版
需要补录：- …　使用正片：第 N 段、第 M 段

## 画面清单
| 编号 | 类型 | 内容 | 对应句子 |

## 来源
- 标题 + 链接

## 标题备选（≤20 字，有反差）
1. …
```

章节名用 2–4 个字或一个英文词，后面做进度条和字幕章节条直接用。存成 `<本期文件夹>/脚本/逐字稿.md`。

## 交稿前

1. 有 koubo-baokuan-check 就跑稿件模式，把“必须改”改完再交。
2. 通读一遍，确认每个事实都有来源、每个【素材】都有真实网址。
3. 交给博主时说明：哪几句需要她补自己的经历，哪几句是短版要补录的。
4. 稿子是她的：可以指出判断不够锋利，但不替她换立场。
