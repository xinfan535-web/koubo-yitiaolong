# 口播爆款自检

在开录之前（或发布之后）用同一套标准体检，回答三件事：这条的播放上限在哪一层？最先卡在哪一关？具体改哪几句、怎么改？
它不预测播放量，只负责把“明显会卡住的地方”在录之前找出来。

## 底层原理（所有判断从这里推）

播放量 ≈ 选题的人群上限 × 逐级流量池的通过率。选题决定上限，留存决定过池，互动（转发、评论、收藏）决定放大。口播没有画面帮忙，留人只靠语言制造的预期差；口播的产品是“人 + 判断”，不是信息：清单带来收藏，判断才带来传播。

## 看输入选模式

| 输入 | 模式 | 检查范围 |
|---|---|---|
| 一句选题或几个备选 | 选题模式 | 只过第一关；多个选题时排序并说明理由 |
| 逐字稿 / SRT / 草稿 | 稿件模式 | 四关全过 |
| 已发布视频的稿子 + 后台数据 | 复盘模式 | 四关全过，并按 [references/review-mode.md](references/review-mode.md) 用数据定位卡点 |

信息不够时只问一个最关键的问题（通常是“这条想让谁看完后转给谁”），其余自己按稿子判断。

## 四道关（按顺序；第一关不过就停在第一关，给换角度的方案）

每关给三档结论：**过 / 险 / 不过**。不打分数。

### 第一关：选题上限——圈外人会在意吗？

1. **一句话测试**：把选题改写成不含术语的一句话，讲给不懂 AI 的职场朋友，对方会不会追问“然后呢”。写出这句话。
2. **人群层级**：最大能触达圈内人（做 AI/做内容的）、职场泛人群、还是大众。只到圈内的，上限就在圈内，如实说。
3. **处境挂钩**：踩在哪个共同处境上——钱、工作、效率、焦虑、身份、关系。一个都挂不上就是纯知识点。
4. **判断还是清单**：核心能不能写成一句可被反驳的判断句。写不出来就是信息整理。

不过时：素材不动，把切入点从“工具/方法”上移到“处境/判断”，给 2–3 个改写后的选题句。

### 第二关：开头缺口——前 3 秒有没有非看不可的理由？

1. **第一句自带缺口**：同时满足“与我有关”和“我不知道答案”。引出第一句原文判断。
2. **没有废开场**：自我介绍、“今天聊聊”、背景铺垫、寒暄，出现即标红。
3. **10 秒内给答案或给承诺**：前 10 秒（约 40–50 字）结束时，观众已拿到结论，或明确知道看完能得到什么。
4. **三件事对齐**：标题、封面字、第一句讲的是同一个承诺。

不过时：给 3 个改写的开头，用不同钩法（有 ra-hook skill 就用它出钩子，没有就自己按“价值包装 / 直击痛点 / 话题开场 / 现象前置”各写一个）。

### 第三关：中段留存——有没有哪 10 秒可以删？

把稿子按约 10 秒（40–50 字）切段，每段贴标签：**兑现**（交付了上一个承诺）/ **开缺口**（抛新疑问、反转、“但是”）/ **可删**（两者都不是）。然后查：

1. **可删段**：删掉后下一句还接得上、信息不少，就建议删。列原文。
2. **连续铺垫**：连续两段既不兑现也不开缺口，标为掉人风险点。
3. **中点重启**：视频一半左右有没有一次重新拉预期（反转、更大的问题）。
4. **口语度**：一句一个意思，没有书面长句和排比腔（有 ra-renhua skill 就用它去 AI 腔）。
5. **结尾**：不提前说“最后”“总结一下”；结尾有身份钩子。

### 第四关：传播放大——有没有一句话值得转给某个具体的人？

1. **金句**：有没有 20 字以内、脱离上下文也成立的判断。引原文；没有就写 2–3 句候选。
2. **转发对象**：能具体说出“会被转给谁、附一句什么话”。说不出，转发大概率起不来。
3. **评论触发**：有可以站队的点，或能让人说“我也是”的经历。“你怎么看”不算。
4. **收藏触发**：有一个可复用的步骤、清单或模板就够。
5. **只押一个**：明确这条主打转发、评论还是收藏，三个都想要通常三个都平。

## 输出格式（固定）

```
# 自检：<选题或标题>
结论：可以录 / 改完再录 / 建议换角度
上限判断：圈内 / 职场泛人群 / 大众 —— 一句理由
最先卡住的地方：第 N 关 —— 一句话

| 关 | 结论 | 关键问题 |
|---|---|---|
| 1 选题上限 | 过/险/不过 | … |
| 2 开头缺口 | … | … |
| 3 中段留存 | … | … |
| 4 传播放大 | … | … |

## 必须改（最多 3 条，按影响排序）
1. 原文：“…” → 改为：“…”　原因：…
## 可以改（可选）
## 中段逐段标签（稿件/复盘模式）
| 段 | 约第几秒 | 原文开头 | 标签 |
## 这条押什么
主打：转发/评论/收藏　金句：“…”　会被转给：…
```

选题模式只输出到第一关并附改写选题。第一关不过时，后三关写“未检查”，不展开。

## 纪律

- 结论先行，第一行就说能不能录。
- 每个问题都引到具体那一句原文，不说“节奏偏慢”这种没法执行的话；指出问题时同时给可直接替换的改写。
- 没问题的关直接写“过”，不凑问题；有硬伤就直说。
- 不承诺播放量，只说上限在哪一层、卡点在哪。
- 必须改不超过 3 条。不替作者改立场，只能指出判断不够锋利。

## 在一条龙里的时机

选题定下来时跑选题模式；逐字稿写完、开录之前跑稿件模式（成本最低的修改时机，录完再改要补录）；发布 3 天后带数据跑复盘模式，结论记进当期复盘。
