# 网页演示素材

口播一条龙的第 2B 步：把逐字稿里的【素材N】做成独立的 mp4。博主不录屏，所有演示由截图合成。
讲法是“指着屏幕讲”：让观众看见这是真页面、看见她说的那句话在哪，不做复杂的点击流程。

**现状**：合成脚本还没有沉淀（之前只留下成品），所以这一步要按下面的规格现写脚本。第一次写完并跑通后，存进本 skill 的 `scripts/`，在这里补上用法，之后直接用。

## 成品长什么样

做之前先抽几帧看参照成品 上一期的 `网页演示/` 文件夹，保持一致。

- 单段 6–10 秒，30fps，h264，画幅和本期一致。
- 背景：和白板图解同一张纸纹底（whiteboard-diagram 的 `assets/`）。
- 浏览器窗口卡片：圆角、轻阴影，顶部窗口栏：左边红黄绿三个圆点，中间地址栏写真实网址（去掉 `https://`）；本地文件夹演示就写路径，如 `~/.agents/skills`。
- 鼠标：黑色箭头指针，平滑移动到要讲的位置。
- 荧光笔：荧光黄 `#FFD640` 半透明，从左到右扫过标题或关键句，一次涂一行，跟着鼠标走。
- 镜头：先给页面全貌（让人认出是哪个网站），再滚动或推近到要讲的段落，文字放大到手机上能读。

| | 竖屏 1080×1920 | 横屏 1920×1080 |
|---|---|---|
| 浏览器卡片 | 上半屏，约 x60–1020、y170–1130 | 作图区 x110–1810、y110–920 内 |
| 下方留白 | 留给字幕（中心约 y1300）和下角的人物角标 | 避开两个下角的角标区（x50–390、x1530–1870，y690–1030）和字幕条 y≈1010 |

## 做法

1. **取页面**：打开逐字稿给的真实网址，截整页长图，桌面版宽度约 1280，高分屏截图（推近后才不糊）。用你能用的浏览器工具或 Playwright（`npx playwright screenshot --full-page <网址> 页面.png`）。用户自己的本地内容（如 skill 文件夹）按真实文件名和内容排一个访达样式的列表页再截图。需要登录才能看的页面，请用户自己截图发来。
2. **定位重点**：找到要讲的标题和句子，用页面脚本读元素的像素坐标，不要目测估。
3. **排动作**：按博主说话的顺序写动作表：停留 → 鼠标移到标题 → 涂标题 → 滚动到段落 → 涂第一句 → 涂第二句。每个动作 0.6–1.2 秒。
4. **合成**：Python（Pillow + ffmpeg，和白板图解同一套做法）逐帧画：纸纹底 → 窗口卡片和阴影 → 裁切缩放的页面区域 → 荧光笔 → 鼠标。缓动用 ease-in-out。
5. **检查**：抽开头、中间、结尾 3 帧：网址对不对、荧光笔有没有涂偏、字在手机上能不能读、有没有进字幕和角标区域。
6. 输出 `网页演示/<编号> <来源>-<要点>.mp4`，编号和逐字稿的【素材N】一致。

## 规则

- 只用真实页面，不伪造页面内容，不改页面上的字。页面打不开或内容和稿子对不上，告诉用户，让她换来源或改稿。
- 地址栏的网址和逐字稿的来源清单一致。
- 荧光笔涂的必须是她那一刻正在说的那句，每段最多涂 3 处。
