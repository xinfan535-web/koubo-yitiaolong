# 口播字幕动画 & 重点标注

目标：**普通字幕安静，重点一眼跳出来，每 5–8 秒给观众一个视觉钩子。** 样式规格、plan 字段、剪映手动做法在 [references/styles.md](references/styles.md)（要改样式或手动做时才读）。

**样式以 references/styles.md 开头的「当前定版」为准**：白字 + 淡黄底条的普通字幕（关键词亮黄）、标题在「白字灰影」和「红条」里选（加标题时先问博主）、同一时刻只出一种字、强调动效时不出字幕、片头片尾加人物介绍。

## 输入

1. 口播视频（竖屏 9:16 或横屏 16:9）。
2. 时间轴字幕：首选剪映导出的 SRT。没有 SRT 就向用户要；只有逐字稿时只出标注表（按句子标，不带时间），说明有了 SRT 才能直接渲染。
3. 逐字稿（可选）：用来纠正 SRT 里的识别错字（尤其 agent、skill、harness 这类英文词）。

只要标注表时，做完第二步就结束。

## 第一步：读稿，挑重点（核心判断）

先通读全文，找到这条视频“为什么存在”的那一句（核心观点），再按下表逐句判断。**没命中任何信号的句子 = 普通字幕。**

| 句子的信号 | 样式（plan 里的 type） | 例子 |
|---|---|---|
| 全片核心观点 / 最后的结论（全片最多 2 处） | `gold` + `big:true`，加 `shrink` 画面缩框 | “用好好过日子的方式” |
| 一个词/短语就是答案、要砸下去 | `punch` 爆点大字 + 蓝色爆炸贴，配 `shrink` | “保证现金流” |
| 对仗 / 前后两句成对 | `gold` 两行，第二行说到时才叠上来 | “卷得动就卷一下 / 卷不动就躺一躺” |
| 有感情、要停一下的金句（非核心） | `gold` 单行 | “真诚而浓烈的情感” |
| 2–4 个并列名词 | `keywords` 逐词出现 | “友情 羁绊 责任” |
| 进入第 N 点 / 新段落 | `chapter` 红条序号：先居中 1.6 秒，再缩到左上角常驻到这一段结束 | “1 整理我的桌面” |
| 具体做法、可以照做的动作 | `checklist` 左上角打勾，逐条累加 | “✅桌下放踏板” |
| 抛出问题 / 设问 | `note` 黄色放字幕上方；问句就是正在说的那句时加 `"replace": true` 让普通字幕让位 | “第一原则是什么？” |
| 博主没说出口的感受/小结（画外批注） | `note` 白色斜放在人物旁，和普通字幕同时在 | 说“闻到柏树的芬芳”时写“工位上的一点森林气息” |
| 画面里的物件/角色有名字 | `sticker` 黄色胶囊贴纸，贴在物件旁 | “大麦” |
| 书名 / 产品名 / 工具名 | `booktag` 黄底标签 | “《小王子》” |

运营×AI 口播的对应：开头抛的问题 → 黄色设问；“三个方法” → 章节红条 1/2/3；具体操作步骤 → 打勾清单；工具名（Claude、飞书）→ 黄底标签；结尾方法论一句话 → 金句大字 + 缩框。
`note`（画外批注）的文字要**自己写**，是对这一句的提炼或调侃，不重复原话，8–12 字以内。

### 节奏规则

- 平均每 5–8 秒一个重点：少了显得平，多了会乱。前 8 秒内必须出现第一个强重点（金句或设问）。
- 强重点（`gold big` / `punch` / `shrink`）之间至少隔 10 秒，全片缩框 ≤ 2–3 次，通常一头一尾。
- 金句、关键词、爆点、章节条出现时普通字幕自动让位；批注、贴纸、标签、清单可以和普通字幕同时在。
- 章节条缩到左上角后一直挂到下一章开始。

## 第二步：先出标注表给用户确认

渲染前给一张表，用户改完再做：

| 时间 | 原句 | 样式 | 屏上文字 | 说明 |
|---|---|---|---|---|
| 00:02–00:04 | 用好好过日子的方式上班 | 金句 big + 缩框 | 用好好过日子的方式 | 全片核心观点 |

## 第三步：写 plan.json，渲染

1. 检查环境：`python3 ../koubo-yitiaolong/scripts/check_env.py`（或确认 ffmpeg 带 ass 滤镜、已装 Pillow、字体在 `~/fonts`；缺字体运行 `bash ../koubo-yitiaolong/scripts/get_fonts.sh`）。
2. 照 `scripts/plan.example.json` 写本期的 `plan.json`（时间单位秒）。`start` 对齐到这句话开口的那一刻（看 SRT），`end` 到说完；多行金句的 `line_starts` 对齐第二句开口。
3. **画幅**：竖屏不用写；横屏在 `config` 里写 `"orient": "landscape"`。坐标按 1080×1920（竖屏）/ 1920×1080（横屏）写，不管原视频分辨率。贴纸、批注的位置先抽一帧看物件和人物在哪再填 x/y，别压脸。
4. 渲染（命令里的 `$SK` 是本 skill 目录，如 `~/.agents/skills/koubo-subtitle-fx`）：
   `scripts/fontkit.py` 是字体查找模块，`koubo_fx.py` 会自动引用，不用单独运行。
   ```bash
   SK=~/.agents/skills/koubo-subtitle-fx
   python3 $SK/scripts/koubo_fx.py plan.json input.mp4 output.mp4        # 出成片，同时留一份 .ass
   python3 $SK/scripts/koubo_fx.py plan.json --ass-only subs.ass         # 只要字幕文件，导进别的软件用
   ```

## 第四步：检查

在每个重点的时间点抽帧拼成一张图看（如 `ffmpeg -i output.mp4 -vf "select=…,scale=270:-1,tile=7x2"`），确认：

- 字没出画、没压脸、没被平台底部 UI 区域挡住（竖屏下方 20%）。
- 金句出现时普通字幕确实消失了；动画在开口那一刻弹出，不早不晚（抽开口前后各 0.1 秒对比）。
- 一行普通字幕不超过 14 字（竖屏）/ 20 字（横屏）；英文单词没被断成两行；金句没超出画面宽度（太长的拆成 `lines` 多行写）。
- 横屏时：字幕条、字号、每行字数已校准，但金句、章节、清单、批注的默认位置是竖屏值，要在 plan 里显式写 x/y 并抽帧确认。

整条口播的剪辑流程（粗剪、镜头、人物角标、音乐、进度条）在 koubo-edit-pipeline。
