# 进度条（只在竖屏长版加）

只在要加进度条时读这个文件。横屏默认不加。

## 规范（已定版，不再问样式）

- 位置：顶部。章节填色：已讲部分填色。
- 底：灰色半透明（约 `#7A7A7A`、50% 透明）；已讲部分：封面同款奶油黄 `#F5F2C4`；章节名：白字加细描边。
- 不要用旧的奶咖色版本（`config_奶咖.json` 已废弃）。
- 章节取自逐字稿的章节名，切点用每部分真正开讲的那一句。

## 用 video-progress-studio（Remotion）

这是 `~/.agents/skills/video-progress-studio/` 里的另一个 skill，按上面这套规范配一份配置模板。没装这个 skill 就先出不带进度条的长版并告诉用户，不要自己重做一套样式。

## 渲染经验（实测验证过）

- 渲染成透明 MOV（ProRes 4444 或 qtrle）的叠加层，再用 ffmpeg overlay 叠到视频上；进度条变化慢，**叠加层用 15fps** 渲染，比 30fps 省一半时间，叠到 30fps 视频上看不出差别。
- 分段渲染（Remotion 的 `--frames` 参数按帧范围分段），再拼接，避免一次渲染被终端超时杀掉；放后台跑并写日志。
- 5 分钟视频在 2 核机器上要 30 分钟以上，Mac 本机更快；提前告诉用户要等多久。
- 叠加位置：上次用 `overlay=0:128`（条带距顶 128px）。它压到了网页演示的地址栏，**建议上移约 80px 再渲染（待定）**；定下来后把数值改在这里。
- 渲染前先出一张静态帧看章节名和切点对不对，再渲整条。
