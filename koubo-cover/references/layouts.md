# 封面版式数值

## 竖屏主版式 1080×1440

从上到下三层：

1. **两行大标题**：占画面上方约 1/3，左右几乎顶满。特粗宋体横向压窄到约 80%（字变瘦高），默认思源宋体 Black；用户指定别的字体就用她的。第一行暖白，第二行奶油黄 `#F5F2C4`；字后加柔和深色投影，保证浅背景上读得清。
2. **黑色胶囊副标题**：紧贴标题下方居中，黑底圆角、细白边；英文关键词亮黄，中文白。
3. **人物**：占下方约 3/5，抠图后加白描边（贴纸感），底部出画，可略偏左或偏右给手势留空间。

背景三选一，都要浅淡不抢字：虚化界面（相关界面截图高斯模糊后提亮冲淡）、方格纸（暖白底 + 浅灰细格）、纯暖白（照片本身够强时）。

## 横屏视频的小红书竖图 1080×1440（明亮极简样张）

- 上半（高 608）：横屏画面。人物抠出来缩小放中间，背景去掉人物后虚化（用周围墙面颜色把人物位置补上，再模糊）；白色手写字（站酷快乐体）加柔和阴影：左上大字 92px（如“AI 三大 / 概念”），右侧右对齐小字 60px（如“3分钟 / 讲清楚”）。
